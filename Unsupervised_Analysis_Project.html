def scree_plot(pca_object, export = False):
    """
    Visualizes a scree plot from a pca object.
    
    PARAMETERS
    ----------
    pca_object | A fitted pca object
    export     | Set to True if you would like to save the scree plot to the
               | current working directory (default: False)
    """
    # building a scree plot

    # setting plot size
    fig, ax = plt.subplots(figsize=(10, 8))
    features = range(pca_object.n_components_)


    # developing a scree plot
    plt.plot(features,
             pca_object.explained_variance_ratio_,
             linewidth = 2,
             marker = 'o',
             markersize = 10,
             markeredgecolor = 'black',
             markerfacecolor = 'grey')


    # setting more plot options
    plt.title('Scree Plot')
    plt.xlabel('PCA feature')
    plt.ylabel('Explained Variance')
    plt.xticks(features)

    if export == True:
    
        # exporting the plot
        plt.savefig('./analysis_images/top_customers_correlation_scree_plot.png')
        
    # displaying the plot
    plt.show()

def scaler(df):
    """
    Standardizes a dataset (mean = 0, variance = 1). Returns a new DataFrame.
    Requires sklearn.preprocessing.StandardScaler()
    
    PARAMETERS
    ----------
    df     | DataFrame to be used for scaling
    """

    # INSTANTIATING a StandardScaler() object
    scaler = StandardScaler(copy = True)


    # FITTING the scaler with the data
    scaler.fit(df)


    # TRANSFORMING our data after fit
    x_scaled = scaler.transform(df)

    
    # converting scaled data into a DataFrame
    new_df = pd.DataFrame(x_scaled)


    # reattaching column names
    new_df.columns = list(df.columns)
    
    return new_df

Component 2 appears to be associated with variables that could represent distinct types or formats of content. Conclusion and recommendations:

We have confirmed that photos are the type of content that generates the most interaction, standing out above other formats in terms of reactions such as "like" and "love". In addition, segmentation based on clustering and principal component analysis has allowed us to identify groups of users with differentiated preferences, which opens the door to a more personalized and effective content strategy.

Recommendations:

  • Consider creating personalized marketing campaigns targeted to each of these clusters. User segments that respond well to "Surprising photos" could receive more impactful visual content, while those that respond better to "Sharing positivity" could benefit from positive, upbeat content.
  • Consider investing in advanced analytics tools to enable even more precise segmentation and personalization of content at the individual level, this could be helpful to tailor content not only according to the type of user, but also according to the time of day or the specific context of each user.
  • Implement a continuous monitoring system that analyzes the performance of different types of content and adjusts the strategy in real time, this will allow the company to remain agile and respond quickly to changes in user preferences.
